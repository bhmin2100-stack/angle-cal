# Photo merge reproducibility samples

Use only `vnand_low_contrast_capture_1.png` through `3.png` as merge inputs.
`00_expected_full_scene_not_input.png` is the expected uncropped scene reference.

The three captures contain the same low-contrast VNAND mold/trench with 150 px vertical overlaps. Exposure, offset, and blur differ per capture, and every input repeats the same 60 px SEM footer with a scale bar. Moving the images to arbitrary board positions must not change the image-derived registration result.
