# Trench analyzer samples

- `01_symmetric_mild_bowing_scale.png`: mild outward bow; the trench void widens smoothly around mid-depth.
- `02_symmetric_medium_bowing_scale.png`: clearer outward bow with a 1 um footer scale bar.
- `03_symmetric_textured_bowing_scale.png`: stronger outward bow, stronger SEM texture, and a clearly labeled 1 um footer scale bar.

In every sample, the left and right walls are intended to be mirror-symmetric, without local kinks, notches, or footing.

These are synthetic SEM-style images intended for UI and algorithm testing. They are not measurement references or real process data.
