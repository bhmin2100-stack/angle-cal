# 영역 분할 실험실 (실험 애드온)

재료명이나 학습 데이터를 입력하지 않고 이미지 전체를 연결 영역으로 나눕니다.
기존 트렌치 측정, 가이드, 프로젝트 파일은 수정하지 않습니다.

## 실행

- 배포 파일: `dist/RegionLab/RegionLab.exe` 또는 저장소의 `RegionLab.bat`.
- 소스 BAT 패키지는 **폴더 전체**를 풀고 `RegionLab.bat`를 실행합니다.
  Python 3.9 이상과 최초 설치 시 인터넷이 필요합니다. `.venv` 생성 및 분할 패키지 설치는
  자동으로 처리합니다. 기존 `.venv`에 분할 패키지가 빠져 있어도 다시 설치합니다.
  `AngleCal.bat`도 같은 설치 검사를 사용합니다. BAT 파일 하나만 복사해서는 실행할 수 없습니다.
- Python이 없는 PC는 독립 EXE ZIP 전체를 풀고 `RegionLab.exe` 또는 동봉한 `RegionLab.bat`를 실행하세요.
- 소스 AngleCal: `영역 분할 실험실` 탭 → `영역 분할 실험실 열기`.
  현재 이미지의 복사본을 전달하며 창에서 다른 이미지도 열 수 있습니다.
- 개발 설치: `python -m pip install -e ".[regions]"`, `python run_region_lab.py`.
- 독립 배포 빌드: `python -m PyInstaller --noconfirm RegionLab.spec`.
  폴더 전체가 필요하며 기존 AngleCal 실행 파일과 별개입니다.
- 배포 계산 검사: `RegionLab.exe --self-test report.json`.
  합성 16비트 띠 영상으로 실제 분할을 실행하고 성공 여부 또는 오류를 JSON에 기록합니다.
- 소스 BAT 검사: `RegionLab.bat --self-test report.json` 또는 `AngleCal.bat --setup-only`.

## 비교 방법

1. 이미지를 열고 **전체 영역 분할**을 누릅니다.
2. 왼쪽 원본과 오른쪽 결과를 휠로 확대하고 드래그로 이동합니다.
3. **색상 겹쳐 보기 / 영역 색상만 / 경계선만 / 원본**을 전환합니다.
4. 영역을 클릭해 ID와 원본 크기 기준 면적을 확인합니다. 선택 해제로 전체를 봅니다.
5. 세밀도·최소 면적 등을 바꾸고 다시 실행합니다. 변경 전 결과는 명시적으로 표시됩니다.
6. 결과 저장은 선택한 상위 폴더에 고유한 실행 폴더를 만듭니다.

## 알고리즘과 설정

Felzenszwalb 그래프 분할을 기준선으로 사용합니다. 인접 픽셀의 영상 특징 차이와
영역 내부 변동을 비교해 연결 영역을 만듭니다. 영역 개수를 강제로 지정하지 않습니다.

- **세밀도**: 클수록 더 세밀하게 나누는 경향. 영역 수의 엄밀한 단조 증가는 보장하지 않습니다.
- **최소 영역 면적**: 분석 해상도의 픽셀 수. 작은 영역을 병합하므로 얇은 막도 사라질 수 있습니다.
- **노이즈 완화**: Gaussian sigma, 분석 픽셀 단위. 0으로 끌 수 있습니다.
- **질감 비중 0**: RGB 밝기·색상 차이를 사용합니다.
- **질감 비중 > 0**: 국소 평균 명암과 sigma=2의 국소 표준편차를 사용합니다.
  이 모드에서는 색상은 제외되고 미세한 구조가 흐려질 수 있습니다.
- **분석 해상도**: 원본 또는 긴 변 제한. 축소 시 결과 ID 맵은 최근접 방식으로
  원본 크기로 확대됩니다. 복원된 정밀 경계가 아니며 UI와 JSON에 실제 분석 크기를 표시합니다.
- 16비트 입력은 전체 최소·최대값으로 선형 정규화합니다. 8비트는 255로 나눕니다.
  알파 채널은 무시합니다. 원본 분석은 메모리 사용을 제한하기 위해 800만 픽셀까지 지원합니다.

## 출력

- `labels.npz`: 원본 H×W의 int32 `labels`, ID 1부터 시작. 픽셀마다 하나의 영역.
- `regions.png`, `overlay.png`, `boundaries.png`: 원본 크기 시각화.
- `result.json`: 설정, 원본/분석 크기, 계산 시간, 영역 수, ID별 면적.
  저장은 화면 선택/불투명도와 무관하게 전체 결과와 기본 50% 오버레이를 기록합니다.

색상과 ID는 해당 실행의 영역 표시이며 재료 또는 신뢰도 의미가 없습니다.
다른 실행 간 ID 대응은 보장하지 않습니다. 장비 정보/스케일바도 영상 일부로 분할합니다.
취소와 종료는 실행 중 계산 단계가 끝난 후 처리하며 취소한 결과는 적용하지 않습니다.

## 검증 범위

합성 영상으로 전체 커버리지, 분리된 동일 밝기 객체, 얇은 띠, 16비트,
축소 좌표 대응, 결정성, 저장 데이터 일치를 검증합니다. 실제 SEM/TEM에서의 정답 경계
정확도는 별도 검증이 필요합니다. 색칠이 그럴듯한 것과 물리적인 경계 검증은 다릅니다.

참고: https://scikit-image.org/docs/stable/api/skimage.segmentation.html#skimage.segmentation.felzenszwalb
